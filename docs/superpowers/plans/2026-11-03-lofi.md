# Lofi Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Lofi, a gamified to-do, budget, focus and music desktop app for Windows, delivered as `Lofi-Setup.exe`.

**Architecture:**
- **`src/core`:** a pure TypeScript domain layer covering the rules, ledger, recurrence, budget, parser, quests, focus and appearance. It's fully unit-tested and has no DOM.
- **`src/store`:** a Zustand store that calls core, persists through an adapter, and emits "moments" for the motion layer.
- **`src/ui`:** React views styled only through CSS design tokens.
- **`electron/`:** the Electron main process handles file storage, the tray, startup, reminders, music import and the hide → pause signal.
- **Browser-only mode:** the renderer also runs in a plain browser with a localStorage adapter, for Playwright screenshots and tests.

**Tech Stack:**
- Electron 38, Vite 6, React 18 and TypeScript 5.
- Zustand and Framer Motion.
- Vitest, Playwright and electron-builder 26 (NSIS, built on Linux via wine64).
- `music-metadata` (in main) for track tags.
- Fonts bundled as woff2 via `@fontsource/*`.

**Spec:** `docs/superpowers/specs/2026-11-03-lofi-design.md`

## Global Constraints

- App name **Lofi**. appId `app.lofi.desktop`. Data lives in `%APPDATA%/Lofi/data.json`, with music in `%APPDATA%/Lofi/music/`. The export file extension is `.lofi.json`.
- **2D only:** no images or illustrations. All visuals are SVG, CSS or canvas shapes.
- Every colour, radius, spacing and font comes from CSS custom properties (tokens); there are no hard-coded colours in components.
- Currency is RM. A money amount is stored as an **integer number of sen**. Display uses `RM 12.50` or `RM12.50` depending on settings.
- All XP values are integers (`Math.round`).
- **Dates:** local-date keys use `YYYY-MM-DD` strings. The budget month is the calendar month. The week starts on Monday by default.
- **Music never plays while the window is minimised or hidden.** Starting with Windows never auto-plays.
- **No coins, HP, town or bundled audio.** UI sounds are WebAudio-synthesized.
- **Copy uses plain words:** "Money in", "Money out", "Left to spend".
- **Progress components:** every progress display uses the shared `ui/shapes/progress` family.

## Review Focus

1. **App closed for several days:** on the next launch, the midnight roll-over must apply one drip per missed day, break streaks for missed habit days, roll quests once, and never double-apply. Test: `rollover catches up 4 missed days exactly once` (Task 10).
2. **Messy amounts:** inputs like `RM12.50`, `12,50`, `.5`, `0` or `-3`, and pasted text in the number pad. Valid input normalises to sen; zero, negative and non-numeric input is rejected with a hint, never saved. Test: `parseAmount` table (Task 5).
3. **Money set up skipped or no budget:** the Money page, safe-to-spend and drip must not divide by zero or show NaN. The hero shows a "Set up your budget" card instead. Test: `monthSummary with no categories` (Task 5).
4. **Undo or edit after a level change:** uncompleting a task, or editing or deleting an entry, must recompute levels from the ledger. Character level only counts lifetime XP, so the number shown must match the ledger. Test: `undo after level-up restores previous level` (Task 3).
5. **Corrupt data or missing music:** a broken `data.json` loads the newest backup. A track whose file was deleted is skipped with a "missing" mark, and playback doesn't stop. Tests: `loadWithFallback` (Task 16) and `player skips missing track` (Task 14).
